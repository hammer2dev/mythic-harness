# LOGO 素材规格

`icons/1024x1024.png` 是本目录唯一的 LOGO 母版。所有尺寸和平台格式均使用同一图案，保留原图的黑色不透明背景、颜色、构图及边距，只进行等比例缩放和格式转换。

## 输出与接口

- PNG：16、24、32、48、64、128、256、512、1024 像素的正方形，文件名为 `<尺寸>x<尺寸>.png`；母版也必须为实际 1024×1024 像素。
- Windows：`icons/icon.ico`，包含 16、24、32、48、64、128、256 像素七个图像帧。
- macOS：`icons/icon.icns`，保留原有图像类型和对应分辨率，包括 `ic04`、`ic05` 的旧格式及 `ic07`–`ic14` 的 PNG 图像。
- 保持原有路径，README 继续引用母版。本目录是素材的唯一来源；UI、桌面和 Web 的图像文件是供各自构建使用的派生副本。

## 应用同步

- UI 统一使用 `packages/ui/src/assets/app-logo.png`，由 512 像素 PNG 复制生成；覆盖左上角、折叠侧栏、首页、登录、引导、启动和更新提示。
- 首页在浅色、深色主题和手机 Web 上使用同一新图案，以等比例适配保留完整图像；装饰图保持低透明度，不遮挡问候语。
- Desktop 与 Web 的 HTML 启动占位使用各自 `public/app-logo.png` 中的 128 像素派生副本，避免 React 挂载前短暂显示旧图案；原有启动完成事件和窗口行为保持不变。
- 桌面 `build/icons` 的九种尺寸、`icon.png`、`icon_windows.png`、`icon_installer.png`、ICO、ICNS 及 `public/icon_512@2x.png` 均同步本目录输出，保留既有路径和尺寸。
- Web 的 `public/favicon.ico` 与 HTML 内嵌 32 像素 favicon 同步新图案。
- 第三方模型与 OAuth 提供商图标保留其品牌身份，不再借用应用打包图标作为其资源来源。
- 本次修改仓库资源，由用户自行重启；已安装发行包需要重新打包安装后才会使用新资源。

## 验收

- 所有文件均能解码，PNG 实际尺寸与文件名一致。
- 所有输出保留完整图案，缩小后仍可辨识，无裁切或拉伸。
- ICO 和 ICNS 内的每个图像均由新母版生成，不能残留旧 LOGO。
- 左上角、首页和启动占位均加载新图片，首页图像不拉伸；Desktop 与 Web 构建可以解析这些资源。
