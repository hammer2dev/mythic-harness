# 本机账号组

桌面 Host 通过本机 MessagePort 提供账号组读写。调用方使用稳定的组和条目 ID，写入返回持久化后的列表。组与条目名称、字段名称在服务端校验，字段值保留原文。

每份列表的首项是固定 ID 的默认组，支持条目操作。Host 拒绝修改或删除默认组本身。旧文件缺少默认组时由 Host 补入，并随下一次写入一起持久化。

独立账号组密文文件是唯一事实源。写入在文件锁中读取、修改和加密，在凭据恢复代次保护下原子替换文件。读取和解密失败均向调用方返回错误并保留文件。系统凭据桥负责密钥与加解密。日志只记录 RPC 名称与受控错误。

见 [环境账号管理规格](../../../../specs/dev-old-experience/account-management.md)。
