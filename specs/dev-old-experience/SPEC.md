# Mythic Harness 4.0 定制功能规格

以 `dev` 的 ZCode 4.0 为实现基线，参考 `dev-old`（`dd1bb160`）上已经实现的交互。

## 项目与会话

- 侧栏使用「分区 → 项目 → 任务」。自定义分区支持新增、改名、折叠、排序和删除。每个项目只属于一个分区，删除分区时项目回到默认「项目」区。独立会话仍归会话区。用项目分区替代任务分组入口。
- 在原工作区用弹窗创建和编辑项目。文件夹选择回到同一份表单草稿，保留名称、目录和主目录。一个项目至少有一个目录，第一个目录默认是主目录，用户可以更换。移除主目录后，下一个可用目录成为主目录。同一个项目的全部目录属于同一个执行环境。
- 保留现有目录信任和远程连接确认。仅在保存成功后更新项目；改名、更换主目录和移除目录关联仍指向原项目，项目归属的任务和磁盘文件保留。项目服务负责目录和项目身份，表单仅持有未提交草稿。
- 置顶区显示置顶项目和原有独立置顶任务。取消置顶后回到原分区，分区已删除时回到默认区。项目置顶仍由 4.0 项目服务保存。分区、位置和折叠状态由侧栏偏好持有，使用 Host 与项目 ID 识别项目。
- 新会话从保存后的主目录启动。既有会话保持自己的 cwd；下一次提交读取最新项目目录。Host 在接受输入时校验并固化目录，排队、执行、重试和恢复读取已持久化的输入快照。子 Agent 沿用父轮目录，权限与目录信任仍由现有执行链判定。
- 桌面实时与远控回放复用同一个项目和输入所有者。连接变更沿用原 workspace identity、owner 和请求失效规则。渲染层仅展示草稿与已接受输入的投影。

## 工作区与设置

- 统一采用编程界面。首次引导直接显示工作记忆、主动任务建议和现有历史会话迁移选项，保留旧用户完成状态和显式偏好。
- 固定一级图标栏，提供项目、定时任务、工作流、插件市场、环境、模型网关和设置。二级栏随模块切换。重复点击当前模块可展开二级栏，切回项目时恢复会话或草稿。设置共用同一外框与导航，移动端使用现有折叠入口。
- 「环境 → Agent应用」是桌面本机程序管理与独立测试入口。产品规则见 [环境与 Agent 应用](agent-applications.md)。
- 「环境 → 账号管理」用于维护本机加密保存的账号组和条目。产品规则见 [账号管理](account-management.md)。
- 一级栏宽 48px，当前模块使用浅底与侧边标记。桌面工作区将二级栏开关合入唯一的应用标志。默认显示标志，鼠标悬停或键盘聚焦时显示收起或展开图标，点击、键盘和原快捷键操作同一个开关。macOS 保留原生窗口按钮的空间。
- 桌面工作区和设置页的一级、二级导航栏共用侧栏主题底色。主工作区贴边布局，去除会话、右侧面板和终端的外框，只留区域之间的分隔线，拖拽手柄照常工作。移除工作区和设置栏底部的「偏好设置」快捷菜单，语言、主题和使用统计从对应设置页进入，桌面缩放仍使用原窗口命令与快捷键。
- 桌面和 Web 共用细滚动条。Chromium 和 WebKit 的横向与纵向滚动槽均为 8px，可见滑块为 4px。其他浏览器使用标准细滚动条。明暗主题沿用各自颜色，保留滚动区的显隐规则和拖动能力。
- 桌面设置和模型网关共用贴边内容区，顶部拖拽区和正文同色，正文贴合右侧和底部。侧栏与内容间保留竖分隔线。普通、窄窗和最大化窗口共用该规则。
- 定时任务页管理 Cron。工作流沿用动态工作流的可用性规则，独立入口按全局和项目展示已保存工作流，详情继续使用已有运行、修订、记录和产物能力。用工作区导航状态记录两个独立目标。两页标题下直接显示任务和工作流内容，空状态及创建、刷新入口保留在各自区域。两页二级导航的概览和详情入口都配对应图标，图标沿用插件市场二级菜单的尺寸和线宽。
- 插件市场集中提供公开市场、个人来源、已安装插件、MCP 服务器、技能和市场源。沿用 4.0 的插件安装、作用域和扩展服务。
- 模型网关的二级导航只列「模型设置」和「使用统计」，两页均移除设置搜索。显示一级导航时，通过项目图标返回工作区。无一级导航的远控网页沿用返回入口。
- 模型设置用一个供应商列表展示名称、Base URL、API 格式、模型数和启停开关，支持按名称和 Base URL 搜索、刷新、编辑和删除。窄窗口把 API 格式和模型数收进供应商行，保留编辑和启停操作。用量中的管理模型入口直接打开对应的供应商弹窗。
- 添加供应商的弹窗先显示自定义入口，再依次显示 OpenAI、Anthropic、DeepSeek、Kimi、MiniMax、BigModel、Z.ai、阿里百炼、Xiaomi、xAI、OpenRouter、OpenCode、硅基流动、腾讯 TokenHub 广州站、火山方舟和阶跃星辰。每个品牌只显示一个预设。点选后在同一个弹窗配置，左上角返回可放弃草稿并重新选。点「完成」后回到供应商列表。
- Renderer 持有新增草稿，Host 只读取规则来预览。获取候选只更新目录，在「添加模型」中搜索、多选或手填 ID 并确认。预设模型和新增模型使用原有「编辑模型配置」弹窗。模型连通性测试继续面向已保存并发布的供应商和模型。

  ~~~text
  供应商列表 → 选预设 → 配置草稿 → 完成 → 目标 Host 一次保存供应商与模型 → 列表
                 ↑         │
                 └─ 返回 ──┘
  ~~~

  预览与拉取目录都使用当前草稿和目标 Host。离开草稿后忽略未完成的预览结果。保存期间禁止重复提交，返回的 Settings View 继续由现有 Hook 接收。

## 模型配置与功能下线

- 模型网关复用 4.0 模型供应商的持久化和凭据接口。获取目录仅刷新候选项，由用户搜索、多选或手填 ID 后确认添加。已知型号使用内置规则，用户可以覆盖配置。模型 API Key 仍经现有凭据服务保存，旧版可用的自定义供应商配置仍可读取。
- 智谱应用账号登录与账号供应商、Coding Plan 购买、订阅、额度统计和账号专用闲时任务下线。保留手动 API Key、自定义模型、应用用量、公共插件与通用 MCP OAuth。依赖智谱登录的官方手机远控暂时下线。本机工作区与 SSH、WSL、Docker 项目连接沿用 4.0 直连流程。
- 桌面一级栏底部的手机图标打开独立的 Bot Channel 弹窗，提供微信、飞书、Lark、Telegram 和机器人管理。使用现有机器人配置、绑定与权限流程，打开弹窗不启动官方手机远控。
- 下线会话分享发布、分享 Web 页面、分享管理、分享链接导入与从链接继续对话。普通会话、现有本地历史和 Claude 会话导入继续可访问。
- 下线产品文档、用户社群、通用问题上报、提交漏洞和产品需求的应用菜单入口，覆盖工作区、设置页、命令面板和系统菜单。桌面问号提供本地工具与版本信息。Web 隐藏桌面工具入口。会话与错误上下文的诊断反馈复用现有反馈中心。
- 下线设置的「项目管理」、设置搜索结果及项目行菜单的「管理项目…」。旧设置位置按现有规则回到常规。同步移除页面专用的批量复核、移除、撤销、恢复与整项目数据清理，以及对应的 Host 命令和 CLI 测量、清理协议。单项目编辑与软删除从侧栏完成。同目录新建时，现有项目编辑器仍可恢复符合条件的已移除项目。归档管理继续使用独立的会话永久删除协议。项目和历史会话按现有数据结构读取。
- 使用 `dev-old` 的透明应用图标，覆盖桌面、安装包和 Web。侧栏分隔线、折叠边框、模型表单控件遵循旧版密度和 4.0 主题令牌。

## 验收

1. 从当前会话创建一个双目录项目，切换主目录并保存。取消编辑时恢复原表单前的项目配置。分区、置顶、取消置顶和删除分区都从侧栏完成。
2. 为既有会话提交两轮消息，并在两轮间修改目录。确认已接受轮次保持旧快照，新输入使用新配置，新会话从新主目录启动。核对桌面和现有直连设备的恢复。
3. 从两级导航进入设置、工作流、插件管理和模型网关。网关两页的二级栏显示两个入口，从一级栏切回项目恢复当前会话。验证模型设置在宽窄窗口下能切换供应商并操作连接和模型，API Key 默认隐藏，获取目录与添加分开。
4. 无智谱账号时可进入工作区并使用自定义模型、公共插件和普通会话。账号、套餐和分享各入口均下线。
5. 核对深浅主题的两级导航底色一致、贴边布局、面板分隔线和 Logo。验证悬停、键盘聚焦、收起和恢复，确认旁边的窗口按钮和拖拽手柄可操作。检查设置页的语言与外观入口。
6. 核对普通列表、工作区和模型管理弹窗的滚动条粗细。验证横向与纵向滚动，并确认主动隐藏滚动条的区域仍可滚动。
6. 在未登录的桌面工作区，从一级栏打开 Bot Channel，验证四个渠道入口和机器人管理，检查弹窗没有官方配对、扫码、链接或登录提示。窄窗滚动渠道列表时，标题和关闭按钮仍可见。
7. 工作区与设置页的问号菜单只提供桌面工具。已有社群或漏洞配置时也不显示已下线的项目。命令面板与原生菜单不再提供对应通用动作。
8. 中英文设置导航和搜索均无「项目管理」，曾停留在该页会回到常规。项目行更多与右键菜单仍能打开编辑器，归档管理可以查看及永久删除归档会话。
